This Python program writes one fixed outage status line to `entry.txt` in the output directory.
The line names what is down, says it is reading a static cache it cannot verify, and refuses to invent a cause or an ETA.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py && cat out/entry.txt
```
